# 永恒轮回战绩查询

AstrBot 插件 · 通过 dak.gg 获取 Eternal Return 玩家战绩、段位与角色数据，生成图片展示。

**开发者：椛椿 & 小休比**

---

## 快速开始

1. 将插件放入 AstrBot 插件目录
2. 安装依赖：`pip install -r requirements.txt`
3. 发送 `/更新资源` 下载游戏资源，视网络及服务器性能可能所需较长时间，请耐心等待（首次使用必须执行）
4. 开始使用，无需唤醒词直接输入命令即可

## 命令一览

### 查询玩家战绩


| 用法 | 说明 |
|------|------|
| `查询玩家 小休比` | 查询当前赛季所有模式最近 10 场 |
| `查询玩家 小休比 S10` | 查询 S10 赛季所有模式最近 10 场 |
| `查询玩家 小休比 20` | 查询当前赛季所有模式最近 20 场 |
| `查询玩家 小休比 S10 20` | 查询 S10 赛季所有模式最近 20 场 |
| `查询玩家 小休比 排位` | 查询当前赛季排位模式最近 10 场 |
| `查询玩家 小休比 钴协议 S10 20` | 查询 S10 赛季钴协议模式最近 20 场 |
| `查询玩家 小休比 匹配 PS10 20` | 查询 PS10 季前赛匹配模式最近 20 场 |

- `查询战绩` 等同于 `查询玩家`
- 赛季范围：S1 ~ S20，季前赛 PS1 ~ PS20
- 场次范围：10 ~ 20，默认 10 场
- 模式：排位、匹配、钴协议、联盟、孤狼、钴联盟
- 默认查询所有模式对局；总览与常用英雄默认取排位数据，无排位数据时回退为匹配模式
- 若该赛季未进行任何游戏，将返回文字提示
- 若该赛季未打排位，图片中 MMR 显示为"段位未鉴定"

### 查询角色数据

| 用法 | 说明 |
|------|------|
| `查询角色 鼻荆` | 查询角色综合数据 |
| `查询角色 暗器 扎希尔` | 查询角色指定武器数据 |
| `查询角色 鼻荆 in1000` | 查询角色指定段位数据 |
| `查询角色 暗器 扎希尔 in1000` | 查询角色指定武器+段位数据 |

段位筛选：`星陨`、`灭钻`、`无瑕`、`修罗`、`in1000`（或 `in100`）

### 查询分数线与排行榜


| 命令 | 说明 |
|------|------|
| `永恒多少分` | 查看永恒/半神分数线及前 5 名玩家 |
| `半神多少分` | 同上 |
| `排行榜` | 同上 |

### 备注功能

| 命令 | 说明 |
|------|------|
| `备注玩家 <真实名> <备注名>` | 添加或更新玩家备注 |
| `删除玩家备注 <备注名>` | 删除玩家备注 |
| `备注角色 <真实名> <备注名>` | 添加或更新角色备注 |
| `删除角色备注 <备注名>` | 删除角色备注 |
| `备注武器 <真实武器名> <备注名>` | 添加或更新武器备注 |
| `删除武器备注 <备注名>` | 删除武器备注 |

设置备注后，直接查询备注名即可自动查询对应真实名称的战绩/数据。

> 玩家、角色、武器的备注池相互独立，同名备注可在三类之间分别使用；查询角色时支持同音字模糊匹配（如输入「扎西尔」可查到「扎希尔」）。

### 小组功能

| 命令 | 说明 |
|------|------|
| `创建小组 <小组名>` | 创建新的空小组 |
| `加入小组 <小组名> <玩家名>` | 向小组中添加成员 |
| `删除小组成员 <小组名> <玩家名>` | 从小组中移除成员 |
| `删除小组 <小组名>` | 删除整个小组 |
| `查询小组 <小组名>` | 查询所有成员的 MMR、段位及平均分（纯文字） |

- 查询小组时会自动解析玩家备注
- 仅统计有排位数据的成员参与平均分计算

## 图片内容说明

### 玩家战绩图片

- 玩家基本信息（名称、等级、MMR、段位图标与名称）
- MMR 折线图（最近 6 个数据点）
- 永恒/半神分数线
- 全球/亚洲排名
- RANK 统计（胜率、平均击杀、平均伤害、平均排名等 12 项数据）
- 常用英雄列表
- 最近对局列表（角色、KDA、伤害、MMR 变化、模式、路径ID、技能、特性等）

### 角色统计图片

- 角色头像与基本信息
- 段位评级徽章
- 数据统计（胜率、TOP3、平均排名等）

## 数据目录

遵循 AstrBot 官方规范，运行时数据存储在 `data/plugin_data/astrbot_plugin_er_profile/` 下：

```text
data/plugin_data/astrbot_plugin_er_profile/
├── assets/                # 游戏资源（角色/装备/图标/段位/技能等）
├── cache/                 # API 缓存 + 同步缓存
│   ├── api/               # dak.gg JSON 数据
│   └── player_sync_cache.json
├── output/                # 输出图片（自动清理）
```


## 自动机制

| 机制 | 说明 |
|------|------|
| 战绩同步 | 查询时自动检测是否需要同步，5 分钟内不重复同步 |
| 同步轮询 | 触发同步后轮询 profile（最多 6 次，每次 2 秒） |
| 赛季更新 | 启动时自动从 API 获取当前赛季；API 不可用时使用 config 中的兜底赛季；`/更新资源` 时检查赛季是否更新 |
| 时间同步 | 启动时同步网络时间，每 12 小时重新同步 |
| 图片清理 | 启动时删除 1 天前旧图，每天凌晨 4 点清空 output 目录 |

## QQ 官方平台（qq_official）

| 能力 | 说明 |
|------|------|
| 图文消息 | 战绩图上传到开放平台「素材管理」后以 markdown 内嵌图片发出，与底部指令按钮合并为**同一条消息**（真正的图文词条），不再拆成「图一条 + 按钮一条」 |
| 指令按钮 | 消息底部按钮：帮助 / 上一赛季 / 下一赛季 / 备注玩家；点击填入指令（群聊只填入输入框，单聊可自动发送，官方限制） |
| 指令面板 | 群聊 / 单聊输入框下方的官方自定义菜单，`/指令面板 同步` 一键创建或更新，`/指令面板 列表` 查看 |
| 降级 | 素材上传或发送失败时自动退回「图片消息 + 按钮消息」两条；非 QQ 平台完全不受影响 |

配置项 `qq_inline_card`（默认开启）控制图文单条消息，`qq_buttons_enabled`（默认开启）控制按钮能力。
素材限制：单张 ≤10MB、png/jpg、每个机器人 100 张（超出时自动清理最早上传的旧图）。

## 注意事项

- dak.gg 更新接口为异步刷新，返回成功不代表数据已更新完成，插件会自动轮询等待
- 角色数据来自 dak.gg 统计接口，可能有延迟
- 首次使用请先发送 `/更新资源` 下载游戏资源，视网络及服务器性能可能所需较长时间，请耐心等待
- 运行时数据存储在 `data/plugin_data/` 下，插件更新不会丢失数据
- 备注数据使用 AstrBot 官方 KV 存储持久化保存
- 小组数据使用 AstrBot 官方 KV 存储持久化保存
